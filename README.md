## 🌟 Proyectos Destacados

- 🛒 [MacKiosco](https://github.com/Scomes02/MacKiosco): sistema de punto de venta, stock y caja para kioscos. Incluye lector de código de barras, **facturación electrónica ARCA** (CAE + QR), arqueo de caja, inventario valorizado y reportes. Se distribuye con instalador para Windows y licencias firmadas por equipo. `Node.js · Express · React · MySQL`
- 🏥 [ReportFlow](https://github.com/Scomes02/ReportFlow): plataforma de gestión de estudios clínicos para el **Hospital Universitario (UNCuyo)**, con 4 roles (Técnico, Médico, RRHH, Call Center), firma de informes con ventana de edición de 24 h y control de acceso por middleware. Desarrollada en un equipo de 6 personas. `Laravel · MySQL · Tailwind · Alpine.js` *(proyecto académico/institucional)*
- 🩺 [Vitalis Manager](https://github.com/Scomes02/Vitalis-manager): API REST de gestión clínica (médicos, pacientes y turnos) con arquitectura en capas, DTOs, mappers y manejo global de excepciones. `Java · Spring Boot · JPA/Hibernate · MySQL`
- 📦 [ReStock](https://github.com/Scomes02/Gestor-Stock): gestión de stock con e-commerce integrado, panel de administración, flujo de aprobación de pedidos y dashboard de ganancias, sobre una **arquitectura MVC propia** sin frameworks. `PHP · MySQL · JavaScript`
- 🛡️ [PaginaSeguros](https://github.com/Scomes02/PaginaSeguros): landing de alta conversión para brokers de seguros, con cotizador multiriesgo, subida segura de archivos (pre-signed URLs) y envío de leads por WhatsApp y email. `JAMstack · Netlify Functions · Cloudflare R2 · EmailJS`
- 🍼 [Puericooltura](https://puericoooltura.netlify.app): plataforma de acompañamiento maternal para una **clienta real**, con CMS headless para que publique contenido sin depender de un desarrollador. `Decap CMS · Netlify Identity` *(repo privado por confidencialidad; demo pública disponible)*
- 👗 [Capibara Store](https://github.com/Scomes02/Indumentary-Capibara-Store-finally): e-commerce de indumentaria desarrollado en equipo, con diseño responsive y carrito de compras. `PHP · MySQL · JavaScript`
- 🔐 [Alverum-Web](https://github.com/Scomes02/Alverum-Web): landing de seguros con chatbot interactivo y formulario de contacto, desplegada en Netlify. `HTML · CSS · JavaScript · Formspree`
- 🛸 [Space Invaders](https://github.com/Scomes02/Space-Invaders-2): juego 2D con física, detección de colisiones y sistema de puntuación. `Unity · C#`
